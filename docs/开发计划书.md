> 版本：v1.0 ｜ 日期：2026-08-13 ｜ 状态：评审通过，进入开发

## 一、项目概述

### 1.1 项目背景

桌面端阅读本地 TXT / EPUB 电子书时，传统阅读器背景固定、窗口不透明，无法实现"只看文字"的沉浸体验。本产品定位为**透明悬浮阅读器**：窗口背景透明度可调，支持完全透明（仅显示文字），文字随窗口大小自适应换行，可置顶并穿透鼠标点击，配合视频、网课、游戏等场景实现"悬浮字幕式"阅读。

### 1.2 项目目标

| 目标 | 说明 |
| --- | --- |
| 核心目标 1 | 背景透明度 0%~100% 连续可调，100% 时完全透明，仅显示文字 |
| 核心目标 2 | 正文随窗口尺寸变化自动重排、自动换行，无横向滚动条 |
| 功能目标 | 支持打开并解析 TXT（多编码）与 EPUB（spine 顺序、章节化） |
| 体验目标 | 大文件（≥10MB TXT）秒开；阅读进度自动记忆恢复 |

### 1.3 使用场景

- 边看视频/直播边读小说（透明悬浮模式）
- 学习课件时对照阅读
- 需要"只看文字"的极简沉浸阅读

### 2.2 非功能需求

- 性能：≥10MB TXT 打开耗时 < 2s；滚动流畅无卡顿。
- 兼容：Windows 10/11（开发优先），架构上兼容 macOS。
- 内存：EPUB 解析仅抽取文本，不加载内嵌图片。
- 健壮性：损坏的 EPUB / 未知编码 TXT 必须友好降级，不得白屏崩溃。

## 三、技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 桌面容器 | Electron | 唯一能实现"真正透明窗口 + 鼠标穿透 + 置顶"的成熟方案；浏览器 Web 无法让窗口透明 |
| 渲染框架 | Vue 3 `<script setup>` + TypeScript 严格模式 | 团队规范；响应式驱动 UI 与透明度/字号联动 |
| 构建 | electron-vite + Vite | 主/预加载/渲染三端统一构建，HMR 开发体验好 |
| 状态 | Pinia | 阅读状态、设置、章节数据集中管理 |
| EPUB 解析 | JSZip + htmlparser2 | 解压 OCF 容器后按 DOM 抽取正文与目录 |
| 编码检测 | iconv-lite | 对 GBK 等非 UTF 编码进行转换与探测 |

> 明确不做：不引入 Web 渲染富文本（epub.js 等重型库），正文统一抽取为纯文本渲染，保证透明场景性能与可控性。

## 四、系统架构

### 4.1 进程模型

```text
┌──────────────────────────── 主进程 (Node.js) ────────────────────────────┐
│  BrowserWindow: transparent / frameless / alwaysOnTop                    │
│  - 文件对话框 + fs 读取                                                   │
│  - TXT 解析（编码检测/章节拆分）  EPUB 解析（JSZip/DOM/TOC）              │
│  - setIgnoreMouseEvents(穿透)  全局快捷键(globalShortcut)                 │
└──────────────▲──────────────────────────────────────────▲────────────────┘
               │ IPC (contextBridge)                       │ IPC
┌──────────────┴──────────────────────────────────────────┴────────────────┐
│                         预加载脚本 preload                                 │
│         暴露 window.readerAPI：openFile / togglePassthrough / ...          │
└──────────────▲──────────────────────────────────────────▲────────────────┘
               │ 类型安全调用                               │
┌──────────────┴──────────────────────────────────────────┴────────────────┐
│                        渲染进程 (Vue3 + TS)                                │
│  ReaderView(正文/换行/滚动)  ControlPanel(透明度/字号/颜色/穿透)           │
│  ChapterSidebar(目录)  stores/reader.ts  composables/useSettings.ts        │
└────────────────────────────────────────────────────────────────────────────┘
```

### 4.3 数据流

1. 渲染进程 `readerAPI.openFile()` → 主进程弹文件框并读取 → 按扩展名分发解析器 → 返回 `{ meta, chapters: [{title, content}] }`。
2. 章节数据写入 Pinia → ReaderView 按章节渲染，滚动位置/字号/颜色实时响应。
3. 设置与进度经 `useSettings` 持久化到 localStorage，重开自动恢复。

## 五、核心模块设计

### 5.1 透明窗口与鼠标穿透（本产品关键）

- 窗口参数：`transparent: true`、`frame: false`、`backgroundColor: '#00000000'`、`alwaysOnTop` 可切换。
- 穿透：`win.setIgnoreMouseEvents(true, { forward: true })`。`forward: true` 使渲染层中 `pointer-events: auto` 的元素（控制面板）仍可点击，正文区域置为 `pointer-events: none` 穿透下层。
- 完全透明：背景透明度 100% 时背景色计算为 `rgba(0,0,0,0)`，正文文字直接悬浮于桌面之上。

### 5.2 TXT 解析

1. 读取 `ArrayBuffer`，按 BOM 判定 UTF-8/UTF-16LE/BE；无 BOM 时先尝试严格 UTF-8 解码，失败回退 GBK（iconv-lite）。
2. 章节拆分：匹配 `第[一二三四五六七八九十百千0-9]+[章节卷部回]`、`Chapter\s*\d+`、卷名行等，生成章节标题与正文段。
3. 边界处理：与文件名相同的首行视为书名行丢弃；首个章节标题前的极短卷首并入首章。

### 5.3 EPUB 解析

1. `META-INF/container.xml` 定位 OPF。
2. 解析 OPF `manifest` + `spine`（保留 `linear`/`properties` 顺序）。
3. 按 spine 顺序加载 XHTML，htmlparser2 抽取标题（h1~h3）与段落文本，生成扁平章节列表。
4. TOC 优先取 NCX（EPUB2）/ nav（EPUB3），缺失时降级用章节标题。
5. 跳过 `head` 区域与 `script/style`，避免元信息混入正文首段。

### 5.4 渲染与自动换行

- 正文容器：`white-space: pre-wrap; word-break: break-word; overflow-wrap: anywhere;`，宽度随窗口收缩，实现纯 CSS 自适应换行。
- 字号、行高、颜色均为响应式变量（`useSettings`），修改即实时重排。
- 窗口 `resize` / 字号变化时按"滚动比例"保持阅读位置不跳动。

### 5.5 设置与进度持久化

- localStorage 存储：背景色/背景透明度/文字色/字号/字体/行高/窗口不透明度/文字阴影、最近文件、每文件阅读进度（章节 index + 滚动比例）。
- 数据模型带版本号，便于后续迁移。

### 5.6 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Shift+O` | 打开文件 |
| `Ctrl+Shift+P` | 切换鼠标穿透 |
| `Ctrl+Shift+↑/↓` | 背景透明度 +5% / -5% |
| `Ctrl+Shift+F` | 切换置顶 |
| `Ctrl+Shift+Q` | 退出 |

## 六、界面设计

- **正文区**：透明背景、纯文字，占满窗口，滚动阅读。
- **顶部控制条**（默认收起，悬停/快捷键唤起）：文件打开、上一/下一章、目录、字号 ±、背景透明度滑块、背景色、文字色、穿透/置顶开关。
- **目录抽屉**：左侧滑出，展示章节列表，点击跳转。
- 视觉风格：极简、无边框、无多余装饰，控件半透明毛玻璃，透明场景下自动淡隐。

## 八、测试方案

1. **编码矩阵**：UTF-8 / UTF-8 BOM / UTF-16LE / GBK 各一份 TXT，断言解析结果正确。
2. **EPUB 样本**：EPUB2（NCX）与 EPUB3（nav）各一份，校验章节数与顺序。
3. **大文件**：生成 15MB TXT，打开耗时 < 2s。
4. **透明/穿透**：背景 100% 透明度 + 穿透模式下文字正常显示、点击穿透；控制面板仍可交互。
5. **窗口自适应**：拖拽缩放窗口，文字实时重排，无横向滚动条。
6. **恢复**：中途关闭重开，章节与滚动位置一致。

## 九、风险与对策

| 风险 | 对策 |
| --- | --- |
| Windows 透明窗口渲染兼容（个别显卡毛边） | 提供"窗口不透明度"兜底方案；控制条不使用系统阴影 |
| 大 TXT 全文经 IPC 传输耗时 | 仅传章节文本，分章传输；解析在子进程侧优化 |
| EPUB 结构五花八门（缺 NCX、加密等） | 多级降级策略 + 解析容错 + 用户可读错误提示 |
| 穿透模式误触导致窗口失焦 | 快捷键快速切换 + 控制面板常驻可点区域 |
